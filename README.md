# AWS Static Website on EC2 

This project demonstrates how to host a static website on an EC2 instance using Apache.

## Steps Followed

1. Launched EC2 instance (Ubuntu)
2. Installed Apache Web Server
3. Hosted index.html page
4. Opened port 80 in Security Grroup
5. Website was live at EC2 public IP 

## Skills Practiced 

- EC2 Setup 
- Apache Web Server 
- Linux Commands
- Hosting on AWS
